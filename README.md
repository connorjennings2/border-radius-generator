# Border Radius Generator

A visual tool for customizing CSS rounded corners.

## Features

- Individual corner controls
- Live preview
- CSS code generation

## How to Use

Adjust each corner and copy the resulting CSS.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Change one corner and inspect the preview.
- [ ] Set all four corners to zero.
- [ ] Copy the CSS and verify the corner order.

Record the observed result and any reproducible issue after running the tests.
